한글 제거와 괄호 기호 제거는 별도 규칙입니다. 괄호 안 내용은 유지하며, 공백은 공백 정리 규칙을 선택해야 정리합니다.

                
대소문자를 구분합니다. 단어는 완전히 일치할 때, 기호는 포함된 위치에서 제거합니다.

              

              

                
모델규격명으로 지정한 열의 현재 대상 전체 행을 검사해 추출 방식을 추천합니다. 발견한 값은 모델명 후보이며, 적용 전 결과를 확인하세요.

                
                

                
                
문자·숫자 조합은 공백으로 나눈 값 중 문자와 숫자로만 된 값을 찾습니다. AB-123·AB_123·AB/123·AB.123은 제외하며, 220V·10KG는 후보가 될 수 있습니다.

                
표기 뒤 값은 공백을 포함해 다음 쉼표·콜론 앞까지 가져옵니다. 줄바꿈이나 다음 MODEL·CODE·GRADE 표기가 나오면 그 앞에서 끝냅니다. 후보가 여러 개면 줄바꿈으로 모두 표시하고 ‘확인 필요’로 남깁니다. 결과와 추출상태는 새 열에 작성합니다.

              

              

                
                
                
                
행마다 필요한 열 수를 계산합니다. 부족한 칸은 빈칸으로 남깁니다. 최대 100개 결과 열을 지원합니다.

              

              

                

                

                

                

                  
                  
                  

                    기준 행과 기준값이 같은 그룹만 처리합니다.
                    기존처럼 앞뒤·연속 공백과 대소문자를 정리해 비교합니다.
                  

                


                

                  기준값이 정확히 같은 모든 그룹을 처리합니다.
                  각 그룹에서 Excel 행 번호가 가장 작은 빈칸 아닌 값을 대표값으로 사용합니다.
                  공백과 대소문자를 구분하며, 필터로 숨겨진 행도 포함합니다.
                  기준값이 누락되거나 그룹의 대상 값이 모두 비어 있으면
                  원본을 유지하고 ‘확인 필요’로 표시합니다.
                


                

                  원본을 유지하고 결과값과 변경여부를 새 열 두 개에 나란히 작성합니다.
                  변경여부는 ‘변경’, ‘유지’, ‘확인 필요’로 표시합니다.
                

              

              

                
                
                
대소문자를 구분해 포함된 모든 문자열을 치환합니다. 바꿀 문자열을 비우면 삭제합니다.

              

              

                
앞뒤·연속 공백과 대소문자를 정리한 뒤 같은 값을 한 그룹으로 봅니다. 대표값을 지정하면 해당 그룹의 모든 행에 적용합니다. 지정하지 않은 값은 유지합니다.

                
                
                
                

                
                
                

              

            

            

            
            
            

              

              

              

              
              
              
기존 열을 유지하고 새 결과 열을 만듭니다. 처리 범위 밖의 행은 빈칸으로 남습니다.

              
              
            

            
            

              

              
현재 값을 최종 결과로 채택합니다. 원본은 유지되며 후속 작업도 계속할 수 있습니다.

              
              
            

          

          

            
어떤 방식으로 유사도를 비교할까요?

            

            
            
            
두 방식 모두 글자 형태를 비교하며, 문장의 의미를 판단하지 않습니다.

            
SequenceMatcher: 같은 순서로 이어지는 공통 부분을 비교합니다.

              샘플 ABCD ↔ XABCD: 공통 부분 ABCD → 약 88.89점.

            
Levenshtein: 글자를 추가·삭제·교체하는 횟수를 비교합니다.

              샘플 ABCD ↔ XABCD: X 한 글자 추가 → 80점.

            

            
            
빈 값은 제외합니다. 공백·대소문자는 자동으로 정리하지 않습니다. 같은 값은 한 번만 비교하고 선택 범위 안의 건수를 표시합니다.

            
최대 50,000쌍까지 비교하며 모든 결과를 새 시트에 표시합니다. 점수는 결과 표에서 정렬·필터할 수 있습니다. 원본을 자동 통합하거나 수정하지 않습니다.
